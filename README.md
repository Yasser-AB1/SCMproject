# Student Grade Calculator

A Java command-line utility that calculates student grades, GPA, and pass/fail status.

## Features
- Enter scores for multiple subjects
- Calculate simple or weighted average
- Get letter grade and pass/fail result
- Export results to a text file

## How to Run
```bash
javac GradeCalculator.java
java GradeCalculator
```

## Versions
- v1.0 — Basic average and letter grades
- v1.1 — Weighted GPA and file export
